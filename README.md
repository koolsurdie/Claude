# IntelliBoard — AI Storyboard Builder for ID Teams

A single HTML file. No installs. No server. Just open it.

## Usage

1. Open `index.html` in Chrome or Edge
2. Click ⚙ API Key in the sidebar and enter your Anthropic API key (stored in your browser only)
3. Click "+ New Project", fill in the form, upload your source document
4. Click "Create & Generate" — Claude builds your storyboard in ~20 seconds
5. Review and edit each screen inline
6. Export to Word (.docx) or Excel (.xlsx)

## Supported Input Formats
- PDF (.pdf)
- Word (.docx, .doc)
- Plain text (.txt)
- PowerPoint (.pptx) — limited, works best as .docx or .txt

## Data Storage
All project data is saved in your browser's localStorage. To share a project with a teammate, use the Export function.

## Deployment
Drop `index.html` anywhere — SharePoint, a shared network drive, a USB stick. No server needed.
